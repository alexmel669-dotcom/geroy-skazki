Политика конфиденциальности

Дата обновления: 5 августа 2026 г.

1. Какие данные мы собираем

При регистрации мы запрашиваем: email, имя пользователя, имя ребёнка, возраст. Эти данные нужны для работы приложения.

Аудиозаписи голоса ребёнка не сохраняются. Они обрабатываются в реальном времени для распознавания речи и синтеза ответа, после чего удаляются.

2. Как мы используем данные

  • Для работы ИИ-персонажа (обращение по имени, учёт возраста)
  • Для отображения статистики в родительском кабинете
  • Для улучшения качества приложения

Мы не продаём данные третьим лицам.

3. Где хранятся данные

Данные хранятся в базе данных Upstash Redis (Европа). Доступ к данным имеет только разработчик.

4. Безопасность

Соединение с сайтом защищено протоколом HTTPS. Родительский кабинет защищён PIN-кодом. Пароли хранятся в зашифрованном виде.

5. Данные детей

Мы осознаём ответственность при работе с данными несовершеннолетних. Мы не запрашиваем фамилию, адрес, фото или другие персональные данные ребёнка. Общение с ИИ-персонажем анонимно.
