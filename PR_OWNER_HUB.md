## Локальная панель владельца проекта

Ветка `codex/owner-hub-release` содержит один релизный коммит поверх `codex/release-process` (`b4fab4d`, PR №5). Для ревью панели выберите эту базу сравнения.

### Что получает владелец

- Главная показывает текущую версию кода, запросы на изменения, задачи проекта и результаты автоматических проверок под русскими заголовками.
- Блок «Готовность к релизу» читает отмеченные строки паспорта. Галочка `[x]` означает выполнение, а `[ ]`, `PENDING` и `BLOCKED` учитываются как незавершённые пункты. В этой версии паспорта выполнены 2 из 6. Решение о выпуске остаётся за владельцем.
- На вкладке «Агенты» журнал обновляется каждые две секунды. Видно время последнего успешного обновления по локальным часам. Начало отмечено синим, ход работы — жёлтым, завершение — зелёным, ошибка — красным. У каждого события есть имя агента. У недавно активной незавершённой задачи появляется пульсирующая точка.
- Диспетчерская формирует наряд для ИИ. Другие вкладки показывают изменения настроенной рабочей папки, паспорт и расходы. Замечания и согласования с SHA хранятся в локальной SQLite вне Git.

### Как проверить

- [ ] На Windows запустить `Start.cmd` и открыть `http://127.0.0.1:8765/`. Сверить пункты прогресс-бара с отметками паспорта.
- [ ] На вкладке «Агенты» проверить изменение часов без F5. Запустить тестовый цикл через `Cycle.cmd`, дождаться событий и сверить цвета и подпись агента.
- [ ] Сформировать и скопировать наряд. Убедиться, что автообновление сохраняет введённый текст.
- [ ] Скопировать `config.example.json` в соседний `config.json`, задать в нём локальный путь к приложению и сопоставить «Изменения» с Git в выбранной папке.
- [ ] Проверить сохранение замечания и согласования после перезапуска на тестовой базе.

На Windows в Edge проверены отображение прогресса и обновление часов с интервалом две секунды.
