# Центр управления на Windows

Дважды нажмите **Start.cmd**. Оставьте открывшееся окно работающим. Откройте в браузере http://127.0.0.1:8765/. Для остановки закройте окно запуска. На этом компьютере уже установлены Python 3 и Git.

В разделе **Агенты** виден журнал. Чтобы выполнить новую синтетическую задачу, дважды нажмите **Cycle.cmd**. Обновление панели происходит каждые пять секунд. В разделе **Изменения** сверху показаны файлы рабочей ветки, ниже — результат последнего тестового цикла.

В разделе **Моя проверка** сверьте SHA, опишите шаги и нажмите **Сохранить замечание**. SHA относится к коммиту. Незакоммиченные файлы панели можно проверить локально. Пишите только обезличенные замечания.

Журнал и замечания остаются в %LOCALAPPDATA%\GeroySkazok\OwnerHub\owner.sqlite. Подкаталог synthetic содержит отдельный Git-репозиторий на каждый запуск тестовой задачи. Production не используется. GitHub проверяется через публичный API без токена каждые пять минут.
